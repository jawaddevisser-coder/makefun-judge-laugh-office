Entry for the [Make the AI Judge Laugh: Office Jokes bounty on make.fun](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

`main.ts` (Node 22, standard library only, deterministic, no network) writes one
original office joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set).

The line:

> Our office has a meeting to plan the meeting, a follow-up to discuss the follow-up, and a calendar invite titled 'quick sync' that has eaten three careers.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/judge-office-out node main.ts
cat /tmp/judge-office-out/entry.txt
```
